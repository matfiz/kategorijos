Lecture 11

Algebras in tensor categories and module categories

A fusion category acts on a category by functors X⊗−X\otimes-X⊗−, one for each object XXX, with coherent associativity and unit isomorphisms. A category with such an action is a module category. This lecture builds module categories from algebras and computes a rank-one module associator. Ostrik’s theorem says that every finite semisimple indecomposable module category comes from an algebra.

By the end of this lecture you will be able to:

  • Define algebras in C\cat{C}C and their modules, and prove that the modules over an algebra form a C\cat{C}C-module category.
  • Write the module pentagon for a rank-one module category over the part of VecGω\VecG[\omega]VecGω​ on a subgroup HHH, and show that it exists exactly when ω∣H\omega|_Hω∣H​ is a coboundary.
  • Compute internal Homs in a semisimple module category, and state Ostrik’s theorem.
  • Classify the indecomposable semisimple module categories over VecG\VecGVecG​ by pairs (H,ψ)(H,\psi)(H,ψ), and list them for Z2\Z_2Z2​.

A module category is not a category of modules: its objects need not be modules over anything. Ostrik’s theorem (§11.3) relates the two.

Theorem 11.10 (Ostrik cited). Let C\cat{C}C be a fusion category over C\CC and M\cat{M}M a semisimple indecomposable C\cat{C}C-module category with finitely many simple objects. For any nonzero MMM in M\cat{M}M, A=[M,M]A=[M,M]A=[M,M] is a separable algebra, and N↦[M,N]N\mapsto [M,N]N↦[M,N] is an equivalence of module categories M≃ModC(A)\cat{M}\simeq \mathrm{Mod}_{\cat{C}}(A)M≃ModC​(A).
